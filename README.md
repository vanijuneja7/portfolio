# 🚀 Vani Juneja – Developer Portfolio

A lightweight, high-performance portfolio website built with **pure React (JavaScript)** and **Vite**, with **zero external icon dependencies** (custom lightweight SVG icons).

---

## ✨ Features

- **Pure JavaScript React**: Clean component architecture using standard React hooks (`useState`, `useEffect`, `useMemo`).
- **Zero Icon Bloat**: All icons are native, lightweight SVGs implemented in pure React (`src/components/Icons.jsx`) — no `lucide-react` or heavy icon packages.
- **Academic & Experience Showcase**:
  - **9.14 / 10 CGPA** at Jaypee University of Information Technology.
  - **JPMorgan Chase & Co.** Software Engineering Virtual Experience.
  - **IBM & Coursera** Back-End Apps with Node.js & Express certification.
  - **IEEE Student Activities** volunteering.
- **Interactive Project Simulators**:
  - **FoodBridge NGO Matchmaker Simulator**: Interactive capacity and urgency scoring demonstration.
  - **News Recommendation System Simulator**: Demonstrates user interest selection and similarity ranking.
  - **Food-to-Recipe Finder Simulator**: Interactive pantry item picker with instant matching percentages.
- **ATS-Formatted Digital Resume Modal**: Includes 1-click **Print / Save as PDF** (`window.print()`).
- **Interactive Skills Matrix**: Real-time keyword search and category filtering.
- **Dark / Light Mode**: Seamless theme toggling with localStorage persistence.
- **Direct Contact Channel**: Interactive contact form with client-side validation, direct email (`vanijuneja7@gmail.com`), and GitHub profile (`github.com/vanijuneja7`).

---

## 🛠️ Tech Stack

- **Dependencies**: React 19, React-DOM (pure React only)
- **Tooling**: Vite, JavaScript (ES6+), Vanilla CSS variables
